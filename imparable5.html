Cybersecurity

Cybersecurity is the discipline of finding, understanding and fixing weaknesses in software, and of assuming an attacker is already probing for them.

How vulnerabilities are found

Reading code for logic errors, fuzzing inputs, and threat-modelling a design before it is built. Most serious breaches come from a simple mistake in one of these, not from an exotic technique.

Classes of weakness worth knowing

Injection flaws when untrusted input reaches a query, broken access control when the server trusts the client, and insecure deserialisation. Broken access control is consistently the most common and most severe, because it needs no special skill to exploit.

Defence in depth

No single control holds. Parameterised queries, least-privilege access, hashed passwords, and keeping dependencies patched each catch what the others miss.
