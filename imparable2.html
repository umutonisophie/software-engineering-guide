Python

Python is the default first language for new programmers and a standard tool for experienced ones. Its appeal is that it reads close to English while still supporting the concurrency and typing needed for serious work.

Why it is taught first

It has no compilation step, so a beginner can write a function and run it immediately. The feedback loop is the whole point: the language gets out of the way of learning to program.

What a working programmer needs beyond the basics

Modules and packages, virtual environments, and a real grasp of exceptions and iterables. The standard library covers more - csv, json, sqlite3, unittest - than most curricula admit, and reaching for a dependency first is usually a mistake.

Where it is genuinely strong

Data work, scientific computing, web backends and scripting. It is a poor choice for anything where predictable latency matters, and being honest about that is part of knowing the language.
