Frontend Mobile

Mobile frontend work applies the same interface discipline to a device with a battery, a thermal limit, a touch screen and an operating system that can kill your process without warning.

The constraints are the design

Mobile users are often on a metered connection, so payload size is a user-facing decision. A slow app on a cheap Android device is a real failure, not an edge case.

Platform specifics

iOS and Android differ in navigation conventions, permission dialogs and review requirements. Flutter and React Native share code across both; a native build in Swift or Kotlin still wins where platform integration is the product.

State that survives

A mobile app is routinely killed in the background, so state has to be persisted and restored deliberately rather than held in memory and trusted.
