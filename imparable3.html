Frontend Web

Frontend web development builds the interface a user interacts with, and owns three problems at once: structure, behaviour, and a rendering model the browser controls.

The three layers

HTML carries meaning, CSS carries presentation, JavaScript carries behaviour. Keeping those concerns separate is what makes a frontend maintainable - the moment presentation logic leaks into scripts, every change risks breaking layout.

Responsive design

A layout has to survive viewports from a 320px phone to an ultrawide monitor. Flexible units, media queries and CSS Grid handle most cases; the discipline is testing at the extremes rather than at one comfortable width.

Accessibility is not optional

Semantic elements give screen reader users structure for free, visible focus states help keyboard users, and colour contrast is a legal requirement in many jurisdictions. All three are cheap when designed in and expensive to retrofit.
