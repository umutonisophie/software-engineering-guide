Internet of Things

Internet of Things work is software for devices that sense and act on the physical world, which introduces failure modes a web application never has.

What changes with physical devices

Sensors report wrong values, networks drop, and devices lose power mid-write. Software has to treat bad input as the normal case rather than the exception.

Security is harder by default

A device may have no screen, may ship with a shared default password, and is often on a home network with no oversight. Devices that are reachable for a decade after purchase make update mechanisms a design requirement, not an afterthought.

Common architecture

A constrained microcontroller reading a sensor, a gateway translating protocols, and a backend that stores and aggregates. The interesting engineering is usually at the boundaries.
